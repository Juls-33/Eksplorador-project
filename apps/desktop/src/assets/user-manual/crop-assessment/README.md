# Crop Assessment captures

Captured on 2026-10-31 from the running native Eksplorador desktop application
using Windows PrintWindow on the app window. The real local database contained
saved crop profiles and no recorded field plots. No records, profile values,
recommendations or sensor readings were inserted or changed for these images.

- `overview.png`: full application client, 2560 × 1406.
- `crop-matrix.png`: portion of the saved-profile list, cropped from overview
  at (435, 135), 563 × 448. The header count includes profiles below the crop.
- `profile-and-plots.png`: selected profile and recorded-plots empty state,
  (1020, 135), 1476 × 180.
- `threshold-rules.png`: saved profile limits, (1020, 337), 1476 × 335.
- `no-data-heatmap.png`: real empty heatmap state, (1020, 695), 1476 × 189.
- `page-controls.png`: category filter and Add Crop Profile control,
  (1987, 45), 510 × 55.

The crops only isolate existing UI; there are no added labels, recolored states
or replaced text. Profile limits are not measured values or endorsed universal
agricultural targets. No populated suitability map was captured because no real
plot samples were available. The guide uses a labeled reference legend based on
the existing source rules instead of fabricated field results.
